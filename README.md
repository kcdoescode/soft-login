# Soft Login

A warm, glassmorphic authentication card featuring fluid 3D flip transitions and real-time input feedback. Crafted with semantic HTML, modern CSS, and vanilla JavaScript.

[**View Live Demo ↗**](https://soft-login-page-by-khushi.vercel.app/)

---

### Design & Interactions

- **3D Card Flip**: Smooth perspective-based flip animation switching between Sign In and Sign Up views without leaving the page.
- **Warm Glassmorphism**: Frosted backdrop-blur panels paired with an earthy caramel and mocha gradient palette.
- **Live Form Feedback**:
  - Dynamic password strength meter with instant visual rating.
  - Real-time confirmation matching that indicates matching passwords on the fly.
  - Show / hide password toggles.
- **Zero Dependencies**: Pure vanilla code with no external frameworks or libraries to install.
- **Responsive**: Fluidly scales across desktops, tablets, and small mobile viewports.

### Getting Started

Simply clone the repository and open `index.html` in any modern web browser:

```bash
git clone https://github.com/kcdoescode/soft-login.git
cd soft-login
```

Double-click `index.html` or serve it using Live Server.
